💡 Key Cryptographic Takeaway: General hash functions (MD5, SHA-256) were engineered for high throughput to checksum multi-gigabyte files. When used for passwords, their speed is a devastating flaw—an attacker with high-end GPUs can calculate 100,000,000,000+ hashes per second. In contrast, PBKDF2 with 100k iterations forces attacker hardware to crawl, making brute force economically impossible while costing a legitimate user only a imperceptible ~50ms login delay.

Module 07 // Cryptographic Foundations

Educational Cryptography Knowledge Base

Essential concepts, mathematical properties, attack methodologies, and modern industry standards for authentication security.

#

What is a Cryptographic Hash?

A cryptographic hash function is a deterministic mathematical algorithm that maps an arbitrary block of digital data to a fixed-size bit string (a digest). Unlike encryption, hashing is strictly a one-way function—there is no decryption key to recover the original message.

📐

Essential Mathematical Properties

  • Determinism: Identical input always generates the exact same hash output.
  • Pre-image Resistance: Computationally infeasible to reverse H(m) back to m.
  • Second Pre-image Resistance: Given m1, it is infeasible to find another m2 where H(m1) = H(m2).
  • Collision Resistance: Infeasible to discover any two distinct inputs yielding the same digest.
🧂

Salting & Rainbow Tables

A rainbow table is a pre-computed lookup database trading storage memory for computation time. Adding a cryptographically random, unique salt to each password forces the attacker to compute a brand new table for every individual user account, rendering billions of dollars of pre-computed tables useless.

⏳

Key Stretching & Work Factors

Algorithms like PBKDF2, bcrypt, and Argon2 incorporate adjustable work factors and memory costs. This intentional computational overhead has negligible impact on authenticating one user (~50ms) but completely destroys mass offline cracking workflows that rely on millions of operations per second.

⚔️

Common Attack Vectors

  • Brute Force: Exhaustively trying every possible character combination.
  • Dictionary Attack: Testing millions of known passwords from leaks (e.g. RockYou).
  • Mask / Hybrid Attacks: Applying word modifications (e.g. replacing 'a' with '@').
  • Credential Stuffing: Re-using stolen login pairs across different services.
🛡️

Modern Security Best Practices

  • Use Password Managers (Bitwarden, 1Password) to generate 20+ character random strings.
  • Deploy Multi-Factor Authentication (2FA) with TOTP or FIDO2 hardware keys.
  • Adopt multi-word passphrases (e.g. correct-horse-battery-staple) for human memorability.
  • Never store plain passwords—always hash with salted Argon2id or PBKDF2.
