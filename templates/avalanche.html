Strict Avalanche Criterion

Formally defined by Webster & Tavares (1985). A function satisfies SAC if complementing any single input bit changes each output bit with probability ½.

🎲

Why ~50% is Ideal

If fewer bits flip, the hash leaks information about the input. If more flip systematically, it creates a predictable pattern attackers can exploit.

🔑

Security Implication

This property ensures that even if an attacker knows most of your password, they gain zero information about the remaining characters from the hash.
