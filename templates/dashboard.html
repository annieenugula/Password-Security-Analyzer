Security Recommendations for Production Systems

🔐
Upgrade to Argon2id

Argon2id (winner of the 2015 Password Hashing Competition) provides configurable memory and parallelism hardness in addition to time cost, making it GPU-resistant beyond PBKDF2.

⏰
Calibrate Work Factor Regularly

Increase PBKDF2 iterations as hardware improves. NIST SP 800-132 recommends ≥ 600,000 iterations for PBKDF2-SHA-256 as of 2023.

🛡️
Enable Multi-Factor Authentication

Even perfect password hashing cannot protect against phishing. TOTP (RFC 6238) or FIDO2 hardware keys eliminate credential theft attacks.

🔒
Rate-Limit Login Endpoints

Implement exponential backoff or account lockout after N failed attempts to mitigate online brute-force attacks.

📋
Audit Log Management

Store only minimal non-sensitive authentication metadata. Never log plaintext passwords, hashes, salts, or full request payloads.

🌐
HTTPS Everywhere

All authentication traffic must be encrypted in transit via TLS 1.2+ to prevent credential interception, even if password hashing is perfect.
