Zero-Knowledge Architecture — Your Password Never Leaves This Server All cryptographic operations use Python's standard hashlib, secrets, and hmac libraries. No plaintext passwords are stored, logged, or transmitted. Hashes and salts are stored only in a local SQLite database on your machine.
Platform Modules

Six Interactive Cryptographic Modules

Password Strength Analyzer

Real-time entropy calculation (E = L × log₂R), criteria checklist, pattern detection, and estimated GPU brute-force crack times.

Module 1

SHA-256 Hash Generator

Generate the deterministic 256-bit SHA-256 digest of any sample input. Demonstrates one-way irreversibility and determinism.

Module 2

Avalanche Effect Visualizer

Compare two near-identical strings. Visualize how a single character change flips ~50% of all 256 output bits (Strict Avalanche Criterion).

Module 3

Secure Registration Demo

Register a demo account using PBKDF2-HMAC-SHA-256 with a unique random salt. Observe key stretching via configurable iteration count.

Module 4 & 5

Password Verification Demo

Simulate server-side login: re-derive the hash with stored salt and verify using constant-time comparison (hmac.compare_digest).

Module 5

Security Dashboard

Aggregated non-sensitive authentication event metrics: registration count, login successes/failures, and algorithm configuration.
