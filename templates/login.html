Timing Attack Prevention

Standard string comparison (==) in Python short-circuits on the first mismatch — returning faster for incorrect guesses. An attacker can measure response times to reconstruct a valid hash one character at a time.

❌ Vulnerable (Timing Attack Risk)
if candidate == stored_hash:
    # UNSAFE: short-circuits early
    grant_access()
✅ Secure (Constant-Time)
if hmac.compare_digest(candidate, stored):
    # SAFE: always same runtime
    grant_access()
⚠️ Username Enumeration Defense
If the username does not exist, the server runs a dummy PBKDF2 derivation anyway. This ensures the "user not found" and "wrong password" responses take the same time, preventing attackers from enumerating valid usernames via timing differences.
